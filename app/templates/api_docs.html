Overview

The Health Navigator API provides endpoints for AI-powered medical consultations, risk predictions, and health data management. All endpoints return JSON responses with consistent formatting.

Base URL: https://api.healthnavigator.ai/v1

Authentication

Authentication is handled through session cookies. Include the session cookie from the login response in subsequent requests.

POST /login

Authenticate user and create session

Request Body

{
  "username": "johndoe",
  "password": "SecurePass123!",
  "remember": false
}
POST /register

Create a new user account

GET /health

Basic health check endpoint

Response

{
  "status": "healthy",
  "timestamp": "2025-01-15T10:30:00Z"
}
POST /api/chat

Send a message to the AI consultation agent

Request Body

{
  "message": "I've been experiencing chest pain lately",
  "conversation_id": "optional-uuid-for-existing-chat"
}
POST /api/predict/heart-disease

Predict heart disease risk based on patient data

POST /api/predict/stroke

Predict stroke risk based on patient data

POST /api/predict/cancer

Predict cancer risk based on symptoms and history

POST /api/predict/medical-image

Analyze medical images (X-ray, MRI, CT scan)

Response Format

All API responses follow a consistent format with status, data, and optional error fields.

Success Response

{
  "status": "success",
  "data": { ... },
  "message": "Optional success message",
  "metadata": { ... }
}

Error Response

{
  "status": "error",
  "error": {
    "code": "ERROR_CODE",
    "message": "Human-readable error message",
    "details": { ... }
  }
}

Error Codes

Code Status Description
UNAUTHORIZED 401 Authentication required
FORBIDDEN 403 Access denied
NOT_FOUND 404 Resource not found
VALIDATION_ERROR 400 Invalid input data
RATE_LIMIT_EXCEEDED 429 Too many requests
INTERNAL_ERROR 500 Server error
